# ToDo Application Backend

### Description
This is a Node.js and TypeScript backend for ToDo-Application and integrated with Firebase Firestore for data storage to store the tasks.

###  Get Started:

You’ll need [Node.js](https://nodejs.org/) installed to run the app.


### Steps:

1. Clone this project to your computer:
   ```
   git clone https://github.com/shaik-mahammad-rafi01/todo-application-backend.git
   ```
2. Open the folder:
   ```
   cd todo-application-backend
   ```
3. Install dependencies:
   ```
   npm install
   ```

4. compile the app:
   ```
   npm run build
   ```
   
4. Run the app: 
   ```
   npm start
   ```
